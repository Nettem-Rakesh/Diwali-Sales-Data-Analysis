# Diwali Sales Data Analysis

## Project Overview

This project analyzes Diwali sales data to identify customer purchasing behavior, sales trends, and business opportunities. The analysis helps businesses understand their customers and make data-driven decisions to improve sales and marketing strategies.

## Objective

The main objective of this project is to:

* Clean and preprocess sales data.
* Perform Exploratory Data Analysis (EDA).
* Identify key customer segments.
* Analyze purchasing patterns.
* Generate actionable business insights.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / Google Colab

## Dataset Information

The dataset contains customer demographic information and purchase details, including:

* Gender
* Age Group
* Marital Status
* State
* Occupation
* Product Category
* Purchase Amount

## Analysis Performed

### Data Cleaning

* Removed null values.
* Handled missing data.
* Corrected data types.
* Removed unnecessary columns.

### Exploratory Data Analysis (EDA)

* Gender-wise purchasing analysis.
* Age group analysis.
* State-wise sales analysis.
* Marital status analysis.
* Occupation-wise analysis.
* Product category analysis.

## Key Insights

* Married women aged 26–35 years contributed the highest sales.
* Customers from Uttar Pradesh, Maharashtra, and Karnataka generated significant revenue.
* IT, Healthcare, and Aviation professionals were among the top buyers.
* Food, Clothing, and Electronics categories showed strong sales performance.
* Female customers contributed more to overall purchases compared to male customers.

## Business Recommendations

* Focus marketing campaigns on women aged 26–35 years.
* Increase promotional activities in high-performing states.
* Offer personalized discounts based on occupation and purchase history.
* Expand inventory in high-demand product categories.


3. Open the notebook:

```bash

```

4. Run all cells to reproduce the analysis.
